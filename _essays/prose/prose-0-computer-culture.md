这是一次分享的讲稿，把几本讲个人管理的书和几门计算机课程放在一起对照来读。

### 《高效能人士时间与管理法则》与《Linux系统高效管理》

- **法则 1：掌握生活的大小事。** 通过掌握时间而掌握生活。
  对应到系统：系统崩溃、分盘、分目录、挂载、分权限、iptables 防火墙、备份、升级。
- **法则 2：确定核心价值。** 核心价值是自我实现和个人成就的基础。
  对应到系统：专门的数据库系统 MySQL、接入请求系统 Nginx、负载均衡 LVS、ZooKeeper 等。
- **法则 3：排定优先级。** 当日常生活反映了你的核心价值时，你就能体验发自内心的平静。
  对应到系统：进程的优先级，硬中断与软中断的区分处理。
- **法则 4：设定可行的目标。** 目标应当合理，且有一定的价值。
  对应到系统：系统分为内核态和用户态，用户态的进程应该做好自己的本分，不要不断尝试去做内核态的角色，而是利用现有系统提供的 API 接口去实现有价值的任务。
- **法则 5：规划好每日工作。** 每日规划做得好，时间宽裕效率高。
  对应到系统：Linux 系统的 crond 定时定点地执行任务，如备份、检查进程的运行状态、重启服务。

### 《高效能人士的七个习惯》与《操作系统分析与设计》

- **由内而外全面造就自己：** 品德、个人魅力、才能。
  对应到系统：核心态负责进程管理、内存管理、文件管理、设备管理；用户态是各种具有不同功能的进程和服务。
- **习惯三：要事第一。** 自我管理的原则。
  对应到系统：进程的优先级、优先级反转、硬中断与软中断的区分处理。
- **习惯四：双赢思维。** 人际领导的原则，与人方便即是与自己方便。
  对应到系统：TCP 拥塞机制的设计，带宽有限，在丢包的情况下，减少数据包的发送。
- **习惯五：知彼解己。** 移情沟通的原则，首先理解他人，进一步让他人理解自己。
  对应到系统：进程通过管道通信，以文本的方式输入到进程，进程处理后再输送到其它进程。因此首要的一点是进程能够理解其它进程的输入，经过自己的处理后输出给其它进程处理。
- **习惯六：统合综效。** 创造性合作的原则，开放思维，倾听意见，提升自我。
  对应到系统：进程通信除了管道外，还有信号量、共享内存、域套接字、TCP/IP 等；实际应用中，多个进程合作协同的通信方式会依据具体场景选择。
- **习惯七：不断更新。** 平衡自我的自我更新原则。
  对应到系统：系统也是不断地升级更新，不断地优化性能和增加新功能。

### 《算法分析与设计》与《人生选择》

- **排序算法**，包括冒泡、插入、希尔、快排、堆排序等。
  当一个优秀的程序员拿到很多很好的 offer，BAT、携程、去哪儿网、大疆……可能他会综合各种因素，并给各种因素设定比例因子，进行排序。
- **贪心算法**：在每一步的选择中，都采取当前状态下最好或最优的选择，从而希望结果也是最好或最优的。
  根据当前自己的目标和需要，选择目前比较好的一种结果，而不去考虑未来的事情。比如薪资高是主要目标，那么就选择一个能给出最高薪资的公司；稳定是主要目标，那么选择大国企；兴趣是主要目标，那么选择利于发展兴趣的公司。==虽然贪心算法有时候急功近利，但如果贪心的方向是正确的，贪心算法也是一种利于解决问题的方式。==
- **动态规划**：与贪心算法最大的不同在于，贪心算法只是做出选择，不能对过程优化；而动态规划会保存以前的运算结果，并根据以前的结果对当前进行选择，会进行过程优化。
  承前启后：每步的选择都是由优化过的子过程来决定；可以回退：当前的选择未必是最优的，可能被未来更多更好的选择抛弃。

### 更多的对照

- **《软件开源》与《人生分享》：** Linux、Apache、Google 人工智能引擎开源……赠人玫瑰，手有余香。IEEE 组织将程序员定义为一种使用 Google、GitHub、Stack Overflow 解决问题的动物。

- **《大数据》与《认识自我》：** 通过对自己的言行举止等数据，对自己进行兴趣的挖掘，或者心理和身体上的异常挖掘。

**上面通过几本书的比较，得出计算机行为与个人管理很相似，因为计算机由人设计，它不但是工具，而且折射出人类文化的进步和思想。** 人类文化、计算机文化、Unix 哲学、算法导论、管理与心理文化、时间与个人管理法则，彼此相通。

## 原文

计算机已经出现了近七十年了，计算机是由人类设计出来的，里面透射出很多的人类思想和文化元素。在《Unix编程艺术》就提及到unix设计的原则和哲学思想，Unix的哲学思想归结为一句话：keep it  simple, stupid ! 现在计算机已经早已进入平民老百姓家，android系统的手机也基本人人有一部，但大家其实并不了解计算机的文化思想，这篇文章就通过几本普通的书与计算机书籍的比较，浅谈一下计算机的文化思想。

### 《高效能人士时间与管理法则》 与 《Linux系统的高效管理》

法则2：确定核心价值 — 核心价值是自我实现和个人成就的基础；每个系统都被定义有核心的价值，如专门作为数据库系统(mysql)，接入请求系统（nginx）, 负载均衡（LVS），zookeeper等，每个系统都能各司其职，那么这些系统就构成了一个很好的解决方案。同样，在这个七彩缤纷的社会上，每个人都有自己的核心价值，各司其职，那么这个社会就能够很好地运转下去。

法则3：排定优先顺序 — 当日常生活反映了你的核心价值时，你就能体验发自内心的平静；排定事情优先级是必须的，就如系统有进程执行的优先级，有硬中断与软中断的设计区分。在系统里， 进程优先级, 优先级最高的，并且最紧迫的事情首先要执行，系统就做对了正确的任务，并且对用户友好；同样对于Linux的硬中断与软中断，硬中断是优先级是紧迫而且需要立即执行，而软中断需要执行但不紧迫，首先处理硬中断IRQ，对于比较耗时间的软中断可以延迟执行如tasklet，workqueue，这样系统才能良好的运行下去，相对于人，就是可持续发展下去，内心达到祥和。

法则5：规划每日工作；linux系统crond可以设置定点定时执行什么类型的事务，定时备份文件，定时查看系统的状态并报警，启动已经挂掉的进程等；而对于人，每天规划好必须做的事情是很有必要的，比如每天早上七点晨跑半小时，晚上十点看书一小时，十一点开始睡眠等，而其它时间就按照事情的轻缓重急的优先级来安排，这个可以动态调整，更好地适应工作和生活。

法则1：掌握生活的大小事--通过掌握时间而掌握生活；在对linux系统的管理上，系统管理员需要管理系统大大小小的事情，如系统崩溃，盘满了，分盘，分目录，如何存储一些/home目录挂载到那个盘上，需不需要继续分盘；如何设定各个用户的权限；怎么在iptables上设置防火墙，免受攻击的灾难；系统管理也有很多琐碎的事情需要系统管理员去处理，但同时也要处理得有条不紊的，这样系统才不会轻易出现问题。同样对于人，如何处理生活的大小事情，是一门需要研究的学问，毕竟繁琐事也需要大量的时间处理，如何提高处理的速度，在系统中，可以使用写shell脚本，避免不断地敲打命令行，并且可以做到复用。而人，怎样可以做到如系统那样高效地处理大小事情，从而让生活好起来。

法则4：设定明确可行的目标；在系统中，分为用户态和内核态，来达到安全管理的目标；处于用户态的进程应该做好自己的本分，不要不断尝试去做内核态的角色，获取其它进程的数据，而是利用现有系统提供的接口api实现有价值的东西。对于人也一样，不能好高骛远，手低眼高，最后却一事无成，竹篮子打水一场空。

### 《高效能人士的七个习惯》 与 《操作系统分析与设计》

由内而外的全面造就自己；Linux系统也是由内而外的全面造就自己，进程管理，内存管理，文件管理，设备管理等都是系统的核心，内功级别的，还具备了与其它系统通信的网络模块，与其它系统交互促进发展，而外是许多由不同服务和进程组成一个多彩缤纷的完美系统；

习惯三：要事第一——自我管理的原则 ；上面也提到，系统中有进程的优先级，有硬中断与软中断的区分处理；还有其它的机制，如反转优先级，做到高优先级的程序能够时时优先执行。个人的处理，更应如是。

习惯四：双赢思维——人际领导的原则；在系统中，网络模块的TCP机制的拥塞机制，带宽是有限的，系统跟其它系统属于竞争资源的关系；在丢包的情况下，按照拥塞算法减少发送数据包，而不是发送更多的数据包导致带宽更加拥塞，其它计算机也同样使用这样的拥塞机制，那么资源虽然紧张，但依然可以进行部分有效的沟通，而不是系统完全瘫痪。在人与人的相处中，也要与人方便，即与自己方便，不能为了一己之私而损害他人的利益，这不但不符合双赢思维，而且会使自己陷入恶性循环。

习惯五：知彼解己——移情沟通的原则；在系统中，进程通过管道间通信，以文本文件的定义格式输送到进程，进程处理后再输送到其它进程；因此首先是要理解其它进程的输入，经过自己的处理后才有更好的输出给其它进程处理，如`cat /usr/share/dict/words | grep purple | awk '{print length($1), $1}' | sort -n | tail -n 1 | cut -d " " -f 2 | cowsay -f tux`，awk不理解其它进程的输入，又怎样处理，别的进程不理解awk的输出，又怎样进行处理。只有进程间都能理解对方的输入和输出，才能很好地协作，系统才能正常地运行。在人与人之间的交流中，也需要首先理解他人，进一步才能他人来了解自己，这样才能真正做到知彼解己，移情沟通，人与人之间才能合作无间。

习惯六：统和综效—— 创造性合作的原则；在系统中，进程间的通信有多种方式：管道、信号量、共享内存、域套接字、tcp/ip等；而在实际应用中，多个进程协同合作的通信选择会依据具体场景选择，如linux系统中的流式文本处理，使用的是管道通信的方式；nginx父进程与多个子进程通信的方式选择共享内存，域套接字；而不在同一台机器上的进程通信使用TCP/IP通信的方式；依据使用场景，选择合适的通信方式，才能做到统和综效。对于人，又怎样做到创造性合作，统和综效呢？开放思维，倾听意见，提高个人素养。

习惯七：不断更新———平衡自我的自我更新的原则；系统也是不断地需要升级，有安全的问题，有崩溃的问题，有用户体验不好的问题，最主要的还是添加新功能 ；而对于人，社会知识和技术都在变化，人也需要不断地学习，才能跟上时代的步伐。同时，人也要不断加强自身，具备特定优质的性格或才能，才能有自己独特的价值。

### 《算法分析与设计》 与 《人生选择》

算法与设计的排序，贪婪，动态规划，Distrija路径 对人生抉择的影响

当一个优秀的程序猿，他拿到许多很好的offer，百度、阿里、腾讯、去哪儿网，豆瓣，知乎，华为等各种土豪公司的offer，但是他犹豫了，为什么呢？看上去很好的offfer，但也有不少令人担忧的事情，比如在北京的百度，不知道要几年才能拿到北京户口，能在北京买房，并且北京的生存环境并不那么理想；不去百度，去腾讯，在深圳，深圳的生存压力也不少，在大公司也只能是做螺丝钉，体现不了自己的价值；不去百度，腾讯，去创业公司吧，薪资高，但不稳定，风险高；在这种难以让人抉择的情况下，一个程序猿会综合各种因素进行一个排序，各种因素的同时设置比例因子，导致排出来的结果更符合客观，然后再从排在前面的进行选择；

现实中的也有懒惰的程序猿，可能会根据自己当前的目标和需要，选择目前比较好的一种结果，而不去考虑未来的事情，比如说有人觉得薪资高是主要目标，那就选择一个能给出最高薪资的公司；有人觉得稳定的工作是其主要目标，那么就会选择一些大国企，如电网，移动等的；但也有人觉得兴趣才是其主要的生存目标，那么就会选择一些乐于自己兴趣发展的公司；这种选择的算法本质是贪婪算法，是一种在每一步选择中都采取当前状态下最好或最优或最有利的选择，从而导致结果也是最好或最优的算法；贪婪算法虽然急功近利，但如果贪婪的方向是正确的，贪婪算法也是一种利于解决问题的方式，而且减少了其它的烦恼和心理压力。

同样存在当前不怕折腾的程序猿，他们认为贪婪算法是一种相当短视的行为，只会根据当前的形式做判断，也就是过早做决定，因而没法达到最优解；因而他们会采用一种更优的算法动态规划。动态规划与贪婪算法最大的不同在于，贪婪只是做出选择，不能过程优化。而动态规划会保存以前的运算结果，并根据以前的结果对当前进行选择，会进行过程优化；动态规划可以做到的两个关键：承前启后，因为逐步的选择都是由优化过的子选择来进一步来决定的；可以回退， 因为当前的选择未必是最优的，可能被未来更多更好的选择抛弃；比如拿到了百度，滴滴打车的offer，上述的第一点会让我们思考，我以前的特长和能力更符合百度还是滴滴打车？百度和滴滴打车谁能给我开启更大的平台？上述的第二点提醒我们，是进入百度后，没有选择好，还可以进入滴滴吗？还是进入滴滴后还可以回退到百度？

现实中大多数人都是很迷茫的，包括程序猿，因为整个社会都比较浮躁和急功近利，导致每个人都想着怎样更快地成功，但同时有不少人连现实中的小事情都没有做好，就去追求那宏大的目标，但还有一个算法提醒我们，那就是Distrija算法，要快速地到达目的地，要首先选择好当前和做好当前的，然后再不断地贪婪和迭代，才能最终顺利地到达目标；就算能选择出最短的路径，路还得去走，才有机会进行下一个轮回的选择。

总的来说，**人生的选择也是一种Trade-Off**；就如算法的选择一样，有时候，要用时间换取空间，有时候要用空间换取时间，使两者达到一个良好的平衡。人生选择了一些，总得还得放弃一些，虽然鱼和熊掌不可兼得，但假如你只喜欢鱼，那就选鱼就够了；同样，只喜欢熊掌，那就选熊掌；可能，还有两者兼得的方案？每个人有每个人的算法，每个算法有每个算法的目的，就算大家使用同样的算法，但是每个人的算法中的那些变量、开关和条件都不一样，得到的结果也不一样。**我们每个人选择的算法决定着我们每个人的选择，我们的选择决定了我们的人生**。

### 《开源》 与 《人生分享》

当年由于unix源码的不公开，导致许多想研究Unix系统的人郁郁不得志，但总有人忍受不了这种状态，于是站出来成立了一个叫做GNU的开源组织，自此之后产生了许多的开源项目，扼要的是gcc，gdb这些编程使用的开源项目，因为Linux Torvalds就是使用这些编程工具开发出初版的linux，之后其它人把最重要的网络模块也写出来之后，linux在服务器的市场就发展得越来越好；开源是一种能够集合全世界优秀的人才共同开发一套系统的方式，linux也只是一个开始；之后linux Torvalds为了让全世界人民更好地进行协同开发，开发出分布式的版本控制系统git，而网页版的github，更是另开源走向一个高峰，更多优秀的人更容易分享项目，其它人也更方便地浏览和修改源代码；基本上github拥有所有出名的开源项目，如apache、hadoop、nginx、nodejs、spark、openstack、go、docker、spark等开源项目。大公司也同样向着开源的路线走，微软开源了.Net的部分源码；IBM拥抱开源，很多的解决方案都采用开源的方案；近期最高人气的是Google开源了其人工智能引擎源码；Facebook，twitter，LinkIn等也进行了不少的开源。IT界的互联网企业拥抱开源的越来越多，开源项目也发展得越来越好。

近期，IEEE组织将程序猿定义为一批只会用Google，github，stackoverflow解决问题的工人。这也是由于开源和分享深入全世界人民的内心，大家都渴望能够开源和分享自己的解决方案，同样当自己遇到问题的时候，也渴望能找到开源或分享的解决方案。这就应和一句熟语：==赠人玫瑰、手有余香==。当然程序猿的分享，不单单是在代码或者是解决方案上，他们是一批实干的人，对人生选择和问题也深有体会，他们乐于分享他们解决问题的方法，倾听大家的意见，从而可以改进他们方法。**乐于分享的人生，是螺旋式增进的人生**，就如开源世界那样发展得越来越好。

类似这样的相似有许多，因为**人类文化与计算机文化同出一辙**

**《分布式计算》 与 《复杂问题解决》**：用mapreduce 分布式的处理的思想来解决人生复杂问题或社会复杂问题。将大问题逐步分解，然后分布式的逐个击破，如果不能分布式，只是速度慢一些，并不影响最终的目的；如秦国击破其它六国，使用离间的方式分解六国连在一起的关系，然后通过远交近攻的方式逐个击破，从而实现真正的大一统。

**《云计算与服务》 与 《生活》**：云计算提供黑盒子的方式，动态扩容伸展，速度迅速而且成本低，用完后即可以归还，如用户量访问比较少的时候，可以使用比较少的资源，当用户量大的时候，可以及时增加资源，从而减少按传统方式所导致的购买和浪费成本。同样，在现实生活中的自己，有时候生活轻松，如意，但有时候生活突然过得艰苦，面对生活的困难，能够及时调整自己，适应环境的挑战，就如云计算与服务这样的黑盒子一样。

**《大数据》 与 《认识自己》**：现在比较热门的技术数据挖掘 和机器学习， 一个跟我们息息相关的是：如何挖掘自己的兴趣，可以通过自己的行为，言论，他人对自己的评价来对自己进行兴趣挖掘；同样也都可以对自己的身体和心理进行挖掘，从而更加能够了解自己，推进这门科学的发展。

**《模式识别》 与 《认识世界》**：找特征，找规律，如人脸识别，图像识别等，但最常用的正则表达式，从大量的字符串中找出相同模式的字符串进行处理。就如牛顿从大量的数据计算中得出万有引力定律，就如爱因斯坦在演算中得到能量守恒定律。

计算机的行为与人的行为如此相似，只因为计算机是由人设计的，==它不但是工具，而且可以折射出人类文明的进步和思想==。
